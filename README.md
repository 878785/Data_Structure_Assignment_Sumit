## 👋 About the Project

This repository contains my **Data Structures assignment using Python**. It includes basic Python programs and implementations of fundamental data structure concepts as part of my academic learning.

The main objective of this assignment is to understand how data structures work and develop problem-solving skills through practical programming.

## 🎯 Objectives

- Understand the basic concepts of data structures.
- Learn array insertion and deletion.
- Implement stack and queue operations.
- Perform matrix operations using Python.
- Practise conditional statements and basic problem-solving.
- Improve programming and logical thinking skills.

## 🚀 How to Run the Programs

### 1. Clone the repository

```bash
git clone https://github.com/878785/Data_Structure_Assignment_Sumit.git
```

### 2. Open the project folder

```bash
cd Data_Structure_Assignment_Sumit
```

### 3. Run a Python program

For example:

```bash
python Array_Ins_Del.py
```

You can replace `Array_Ins_Del.py` with the name of any other Python file in the repository.

**Prerequisite:** Python must be installed on your computer.
